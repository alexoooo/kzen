# IDE inspection sweep — 2026-06-21 (kzen umbrella)

Classification of the IntelliJ **Inspect Code** export (`audit/ide/*.xml`, captured 2026-06-21) across all five
siblings, performed as the IDE-cleanliness half of the Gradle 9.6.0 / Kotlin 2.4.0 toolchain update. The export
held **66 inspection categories** with **~3,100 hits**. This sweep applied only the **mechanical,
no-behaviour-change** subset; everything semantic, opinionated, or non-code was deliberately left.

> **Scope caveat — read before interpreting `git diff`.** At capture time the working tree already contained a
> large, *unrelated*, uncommitted refactor (a GraphEnvironment / `@Service` construction-time DI change plus a
> project-wide IntelliJ "Optimize Imports" pass — ~90 files in kzen-auto alone, pure import reordering with no
> code change, plus staged-added/worktree-deleted `GraphEnvironment.kt` and notation fixtures). **That refactor
> is NOT part of this audit and was not produced by it.** Only the edits enumerated in §"Applied" below are
> attributable to this sweep. Do not read the full working-tree diff as "the IDE sweep."

The export was deleted after this report was written (per the `audit/` convention — only the MD persists; re-run
IntelliJ → Analyze → Inspect Code to regenerate).

## Skipped — 56 categories, with rationale

### Intentional codebase conventions — leave (fighting these would regress the codebase)

| Inspection | Occ | Why skipped |
|---|---:|---|
| `ConstPropertyName` | 338 | Deliberate naming convention; already `@Suppress`ed widely (~42). Not a defect. |
| `RedundantSuppression` | 101 | In KMP a suppression redundant on one target can be **load-bearing** on another (jvm/js/metadata compile differently). Removing risks breaking a sibling target's compile; not mechanically safe. |
| `MoveVariableDeclarationIntoWhen` | 4 | Stylistic; codebase favours the explicit declaration. |
| `MayBeConstant` | 8 | `val`→`const val` can shift ABI / reflection visibility; not a pure cleanliness win. |
| `RemoveEmptyPrimaryConstructor` | 1 | Carries an intentional comment. |
| `RedundantEmptyInitializerBlock` | 1 | Holds commented-out code (intentional parking). |

### Semantic / API / behaviour risk — out of "mechanical" scope (needs human judgement)

| Inspection | Occ | Why skipped |
|---|---:|---|
| `UnusedSymbol` + `unused` | 217 + 88 | Dead-code/API removal. Many targets are `@Reflect`/framework-referenced or deliberate public SPI surface — invisible to static analysis. Behaviour/contract risk. |
| `SameParameterValue` / `SameReturnValue` / `UnusedReturnValue` / `EmptyMethod` / `CanBeParameter` | 13/6/1/7/2 | Signature & dead-code analysis; semantic. |
| **`KotlinConstantConditions`** | **9** | **Possible real bugs** (always-true/false conditions). Worth a focused human review — see follow-ups. |
| **`LossyConversionCompoundAssignment`** | **4** | Possible real bug (narrowing in `+=` etc.). Review individually. |
| `KotlinArrayToString` | 3 | Possible bug (`.toString()` on an array). Review. |
| `NullableProblems` / `HasPlatformType` / `RedundantNullableReturnType` | 1/1/2 | Nullability contract; needs care, not mechanical. |
| `RunBlocking` / `SuspendCoroutineLacksCancellationGuarantees` | 1/6 | Concurrency/cancellation — behaviour-sensitive. |
| `NonStrictComparisonCanBeEquality` | 2 | Borderline; semantic intent. |
| `HttpUrlsUsage` | 3 | `http://` may be intentional (localhost / loopback). |
| `PackageDirectoryMismatch` | 3 | Structural file moves. |
